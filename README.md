## ✨ Features
- 💻 **AI Code Generation** – Generate Java code snippets instantly  
- 🔍 **Code Analysis** – Detect bugs & suggest improvements  
- 📚 **Documentation Generation** – Auto-generate docs for functions/modules  
- ⚙️ **Refactoring Suggestions** – Improve readability & maintainability  
- 🔗 **GitHub Integration** – Analyze repositories directly  
- 🧠 **Code Explanation** – Understand complex codebases faster  
- ⚡ **Auto-fix Proposals** – Suggest fixes with developer approval  
- 🌐 **Web + IDE Plugin** – Access via web platform or VS Code plugin
