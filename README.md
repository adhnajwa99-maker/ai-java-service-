The goal of CodeGenius is to create an intelligent AI developer assistant capable of understanding full codebases and helping developers build better software.

✨ Features

💻 AI Code Generation
Generate code snippets quickly.

🔍 Code Analysis
Detect bugs and suggest improvements.

📚 Documentation Generation
Automatically generate documentation for functions and modules.

⚙️ Refactoring Suggestions
Improve readability and maintainability.

🔗 Git Repository Integration
Analyze GitHub repositories directly.

🧠 Code Explanation
Understand complex codebases faster.
